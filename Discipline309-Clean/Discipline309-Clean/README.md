# 309 Day Discipline — Clean Android Project

Clean rebuild of the Discipline 309 app with the same core features:
- 309-day target countdown (01 Aug 2027)
- Daily 6-item checklist
- Completion percentage, current streak and best streak
- Local/offline storage
- Daily alarms with exact-alarm support
- Notification + Sinhala Text-to-Speech attempt
- Alarm rescheduling after reboot/time changes
- Offline Sinhala/English discipline assistant
- Notification and exact-alarm permission guidance

The project includes a GitHub Actions workflow that builds `app-debug.apk` and uploads it as an artifact.
